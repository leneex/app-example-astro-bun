# Astro на Bun

Пример приложения [Astro](https://astro.build/) на [Bun](https://bun.sh/).

## Параметры деплоя

Выберите рантайм **Bun**, фреймворк **Astro** и тип приложения **frontend**. Для frontend будет опубликована статическая сборка.

| Параметр | Значение |
| --- | --- |
| Фреймворк | Astro |
| Версия Bun | 1.2 |
| Тип приложения | `frontend` |
| Команда сборки | `bun run build` |
| Директория сборки | `dist` |

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
bun install

# запуск в режиме разработки
bun run dev

# сборка для продакшн
bun run build

# просмотр собранной статической версии
bun run preview
```
